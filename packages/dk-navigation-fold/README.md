# 侧栏分组切换 · dk-navigation-fold

本地独立 DSH 插件，把侧栏的功能导航和工作区列表放到顶部的两个标签里，一次只展示一组。不替换官方侧栏，也不修改应用安装包。

## 使用

- 「新会话」下方出现两个标签：**功能导航**（左）和 **工作区**（右）。标签固定在滚动区之外，滚动列表时位置不变，也不会再被另一组内容的高度推着走。
- 默认展示工作区；点击或按方向键切换后只渲染所选分组，另一组隐藏。选择保存在 localStorage 的 `dk-navigation-fold:panel:v1`（`workspace` 或 `navigation`），刷新后恢复。
- 工作区标签的文字直接取宿主标题（中文「工作区」、英文「Workspaces」等），不复制文案；功能导航标签跟随宿主当前语言：中文「功能导航」，其他语言回退「Navigation」。切换语言即时更新文字，不重建标签，也不重置选择。使用宿主同步的 `<html lang>`，不另存语言偏好或按操作系统语言猜测。
- 标签采用 ARIA 页签语义（`role=tablist/tab`、`aria-selected`、`aria-controls`），只有当前标签进入 Tab 顺序；左右/上下方向键、Home、End 在两组之间切换。
- 工作区标题不再重复显示，原位置用等高占位补齐宽度，搜索、视图及新增按钮保持原位与原有行为。宿主展开工作区搜索时自动切回工作区标签并让出整行宽度；收起搜索不跳回。
- rc.2 展开侧栏中，标签栏上方（新会话之后）保留 8px 外距；标签下方利用首个菜单行自身的内部留白，移除额外的 8px 网格空行、标签下边距和滚动区上边距，避免透明菜单行让视觉空隙叠加。菜单项高度、内部间距及工作区自身布局不变；代码契约测试不代表文字可见边缘的像素验收。
- Logo、新会话、设置及官方“整个侧栏开关”保持原状。原有入口和列表不被移动或重新实现。
- 在插件管理中停用或卸载 `dk-navigation-fold` 可恢复原导航与工作区；本地选择保留，方便重新启用时恢复。旧版折叠偏好（`dk-navigation-fold:collapsed:v1`、`dk-navigation-fold:workspaces-collapsed:v1` 及 `dsh-navigation-fold:*`）不再读取，也不再写入，文件里留存的旧值不删除。
- 从旧包名 `dsh-navigation-fold` 升级：先移除旧安装，再安装并启用 `dk-navigation-fold`。插件包名、入口 id 和 DOM 标记均已切换为 `dk-` 前缀，旧安装需重装。
- 安装或重新构建后，可在插件管理中停用再启用本插件，让宿主重新读取产物；不需要启动新的 Web 服务。若仍无标签栏，需检查启用状态及 DOM 兼容性，刷新或重启不能修复结构失配。

## 边界与兼容性

宿主提供普通插件加载与生命周期，但当前没有公开的“侧栏分组切换”插槽。因此此插件以结构化 DOM 适配器增强原侧栏：从 `data-sidebar-toggle` 向上定位唯一的侧栏根，要求其中恰有一个带 `aria-label` 的导航，且导航的下一个兄弟区域包含官方 `[data-slot="sidebar.workspaces"]`；不依赖翻译文案、散列 CSS 类名或固定层级。

- 只有唯一匹配的侧栏会被增强；无法定位、匹配不唯一或缺少工作区标题时恢复原侧栏，不隐藏任何一组，也不接管其他菜单。
- 已核对 DSH `0.2.2-rc.1` 与 `0.2.2-rc.2` 的展开结构。`0.2.2-rc.2` 把导航移入 `[data-sidebar-scrollport]` 网格滚动区，导航与工作区区域仍是相邻兄弟；侧栏开关位于标题条/Logo 行，不再与导航同容器。插件因此以“唯一导航 + 后继工作区插槽”识别侧栏根，并把标签栏插在包含导航的根级子元素之前（即滚动区之前），不进入网格；仅当标签栏紧邻该滚动区时，把网格首行与两组之间的空行收为 0。
- 工作区仍要求：导航后的区域内先有官方 `SlotOutlet` 的 `[data-slot="sidebar.workspaces"]` 容器（`display:contents` 不代表不存在 DOM 节点），其中唯一的浏览器容器直接包含标题栏与列表；标题栏有直接标题 `span` 及唯一搜索输入框/展开按钮。窄侧栏没有标题，因此不接管，保留宿主原有图标排布。
- 隐藏的标签面板使用 `display:none`，其内容不进入渲染树、Tab 顺序和无障碍树；代价是切到功能导航时，宿主的工作区搜索快捷键无法聚焦被隐藏的搜索框，需要先切回工作区标签。宿主若以编程方式展开搜索，插件会自动切回工作区。
- 官方渲染重建节点后自动重新定位并保持当前选择；停用时撤销样式、标签、占位、隐藏标记、生成的 id 和监听。
- 独立保存可避免被官方安装包更新直接覆盖，**不代表官方支持的永久兼容接口**；官方改变 DOM 后可能需要适配。
- 声明的 DSH 版本范围是 `^0.2.2-rc.1`，已核对 rc.1 与 rc.2；后续预发布版本仍可能因版本守卫需要主动评估后升级声明，不能绕过兼容守卫。
- 本插件无网络请求、不读取凭据、不注册代理工具，无运行时 npm 依赖。

## 开发与检查

需要 Node >=22.19、pnpm。`jsdom` 仅是开发依赖。在本仓库根目录执行：

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm --filter dk-navigation-fold test
pnpm --filter dk-navigation-fold build
pnpm --filter dk-navigation-fold check
```

安装时使用本地包来源 `link:<本仓库绝对路径>/packages/dk-navigation-fold`。生成产物不入库，安装前必须 build。详见[项目说明](../../README.md)。

源码在 `src/navigation-fold.js`，构建脚本生成 ModuleLoader 格式的 `lib/client.js`。修改源码后必须重新构建；普通源码编辑不会自动更新此 GUI。

测试覆盖：默认分组与切换、标签文字取宿主标题、中英文初始语言与原地切换及英文回退、页签 ARIA 与键盘操作、工作区标题占位与工具按钮可见、搜索展开自动切回、rc.1/rc.2 定位与 rc.2 网格间距、只影响相邻滚动区、选择持久化与旧 key 忽略、侧栏重建、定位失效/歧义/窄侧栏时放开、存储异常、公开模块入口与停用清理。JSDOM 对继承的 CSS 变量解析不完整，颜色、像素对齐及原生按钮位置需另用真实浏览器检查；独立 DOM 或官方样式重放都不等同于已登录桌面 GUI 的端到端验证。
