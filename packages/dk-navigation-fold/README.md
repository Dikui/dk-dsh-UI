# 侧栏分组折叠 · dk-navigation-fold

本地独立 DSH 插件，可分别收起功能导航和工作区列表，不替换官方侧栏，也不修改应用安装包。

## 使用

- 「新会话」下方出现 **功能导航** 按钮，点击收起或展开整组入口（包括「更多」）。标题跟随宿主当前语言：中文显示「功能导航」，英文显示「Navigation」，其他语言暂回退英文；切换语言即时更新可见标题和无障碍名称，不重置折叠状态。使用宿主同步的 `<html lang>`，不另存语言偏好或按操作系统语言猜测。
- 点击 **工作区** 标题前的箭头可收起或展开整组工作区及会话列表；平铺视图沿用原来的「会话」标题，不额外增加一行。
- 两组默认展开，各自记忆状态。功能导航使用 localStorage 的 `dk-navigation-fold:collapsed:v1`，工作区使用 `dk-navigation-fold:workspaces-collapsed:v1`；改名前的 `dsh-navigation-fold:*` key 只作为读取回退，新状态写入新 key，旧偏好因此不会丢失。存储受限时仍可在当前页面使用。
- 两组折叠标题统一箭头与文字起点、字号、字重、颜色及 36px 标题行高，使用宿主侧栏的行缩进与图文间距变量；不额外叠加工作区缩进。悬停仅强调文字与箭头，不显示大小不一的胶囊底色，也不弹出重复的原生标题提示；键盘焦点仍有清晰轮廓。
- 工作区标题及其右侧空白都可点击折叠，点击范围止于工具按钮之前。搜索、视图及新增按钮保留原有行为与布局，使用这些操作或搜索快捷键时自动展开列表。搜索输入框展开时让出标题空间。
- Logo、新会话、设置及官方“整个侧栏开关”保持原状。原有入口和列表不被移动或重新实现。
- 在插件管理中停用或卸载 `dk-navigation-fold` 可恢复原导航；本地偏好保留，方便重新启用时恢复状态。
- 从旧包名 `dsh-navigation-fold` 升级：先移除旧安装，再安装并启用 `dk-navigation-fold`。插件包名、入口 id 和 DOM 标记均已切换为 `dk-` 前缀，旧安装需重装；旧 localStorage key 仍会被读取一次作为回退。
- 安装或重新构建后，可在插件管理中停用再启用本插件，让宿主重新读取产物；不需要启动新的 Web 服务。若仍无开关，需检查启用状态及 DOM 兼容性，刷新或重启不能修复结构失配。

## 边界与兼容性

宿主提供普通插件加载与生命周期，但当前没有公开的“整组导航折叠”插槽。因此此插件以结构化 DOM 适配器增强原侧栏：从 `data-sidebar-toggle` 向上定位唯一的侧栏根，要求其中恰有一个带 `aria-label` 的导航，且导航的下一个兄弟区域包含官方 `[data-slot="sidebar.workspaces"]`；不依赖翻译文案、散列 CSS 类名或固定层级。

- 只有唯一匹配的侧栏会被增强；无法定位或匹配不唯一时恢复原导航和工作区，不隐藏其他菜单。
- 已核对 DSH `0.2.2-rc.1` 与 `0.2.2-rc.2` 的展开结构。`0.2.2-rc.2` 把导航移入 `[data-sidebar-scrollport]` 网格滚动区，导航与工作区区域仍是相邻兄弟；侧栏开关位于标题条/Logo 行，不再与导航同容器。插件因此以“唯一导航 + 后继工作区插槽”识别侧栏根，并把功能导航开关插在包含导航的根级子元素之前（即滚动区之前），不进入网格。工作区仍要求：导航后的区域内先有官方 `SlotOutlet` 的 `[data-slot="sidebar.workspaces"]` 容器（`display:contents` 不代表不存在 DOM 节点），其中唯一的浏览器容器直接包含标题栏与列表；标题栏有直接标题 `span` 及唯一搜索输入框/展开按钮。不按中文文案或散列 CSS 类名定位，不穿透任意未知容器。
- 窄侧栏无标题时不接管工作区；工作区结构失配时恢复原标题和列表，功能导航仍可独立使用。
- 官方渲染重建节点后自动重新定位；停用时撤销样式、按钮、隐藏标记、生成的 id 和监听。
- 独立保存可避免被官方安装包更新直接覆盖，**不代表官方支持的永久兼容接口**；官方改变 DOM 后可能需要适配。
- 声明的 DSH 版本范围是 `^0.2.2-rc.1`，已核对 rc.1 与 rc.2；后续预发布版本仍可能因版本守卫需要主动评估后升级声明，不能绕过兼容守卫。
- 本插件无网络请求、不读取凭据、不注册代理工具，无运行时 npm 依赖。

## 开发与检查

需要 Node >=22.19、pnpm。`jsdom` 仅是开发依赖。在本仓库根目录执行：

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm --filter dk-navigation-fold test
pnpm --filter dk-navigation-fold build
pnpm --filter dk-navigation-fold check
```

安装时使用本地包来源 `link:<本仓库绝对路径>/packages/dk-navigation-fold`。生成产物不入库，安装前必须 build。详见[项目说明](../../README.md)。

源码在 `src/navigation-fold.js`，构建脚本生成 ModuleLoader 格式的 `lib/client.js`。修改源码后必须重新构建；普通源码编辑不会自动更新此 GUI。

测试覆盖：两组独立收起/展开、标题字号与行高一致、无原生标题气泡且保留无障碍名称和状态、中英文初始语言与原地切换及英文回退、工作区标题操作与焦点恢复、搜索/分组文案适配、独立状态持久化与旧 key 回退、rc.2 网格滚动区定位与侧栏重建、节点重建、定位失效/歧义时放开、延迟挂载、存储异常、公开模块入口与停用清理。JSDOM 对继承的 CSS 变量解析不完整，颜色、像素对齐及原生按钮位置需另用真实浏览器检查；独立 DOM 或官方样式重放都不等同于已登录桌面 GUI 的端到端验证。
